# Hashem Alhamed — Portfolio & CV

Interactive cyberpunk 3D portfolio + ATS-friendly CV for **Hashem Zaid Aidaroos Alhamed**.

**Live:** https://hashem-portfolio-six.vercel.app · **CV:** https://hashem-portfolio-six.vercel.app/cv

## Live Sections

| Route | Description |
|-------|-------------|
| `/` | 3D scroll portfolio (Three.js + Framer Motion) |
| `/cv` | ATS-friendly CV — print to PDF (Ctrl+P) |

## Stack

- **Next.js 16** · TypeScript · Tailwind CSS v4
- **React Three Fiber** · Drei · Three.js
- **Framer Motion**

## Run Locally

```bash
cd hashem-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## CV (ATS)

1. Go to `/cv`
2. Click **Print / Save PDF**
3. Choose "Save as PDF" — single column, no graphics, ATS-safe

## Deploy (Vercel)

```bash
npm run build
# Push to GitHub → Import on vercel.com
```
